# Branche `ressources`

## Rôle de la branche

La branche **`ressources`** regroupe les **documents et liens utiles** pour réaliser la SAE *Prévision de données temporelles*.

Elle sert de **support documentaire** pour :
- comprendre les notions utilisées
- trouver de l’aide méthodologique
- s’appuyer sur des ressources externes

Cette branche ne contient **pas le code final du projet**.

---

## Contenu

Cette branche peut contenir :
- des fichiers explicatifs
- des notes personnelles
- des liens vers des ressources externes
